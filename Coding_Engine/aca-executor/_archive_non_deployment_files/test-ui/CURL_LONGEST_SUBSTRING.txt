ALGORITHM:
================================================================================
Sliding Window Technique:
- Use a hash map to track the last occurrence of each character
- Maintain a window [start, end] with no repeating characters
- When a duplicate is found, move the start pointer to the right of the last occurrence
- Track the maximum window size

Time Complexity: O(n) where n is the length of the string
Space Complexity: O(min(n, m)) where m is the size of the charset
